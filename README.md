# LocKit
LocKit — это легковесный, высокопроизводительный десктопный инструмент для локализации инди-игр с глубокой интеграцией искусственного интеллекта (LLM). В отличие от устаревших решений (например, Translator++ на базе NW.js), проект изначально спроектирован для работы с огромными текстовыми базами (более 100 000 строк) без задержек интерфейса и с минимальным потреблением оперативной памяти.
